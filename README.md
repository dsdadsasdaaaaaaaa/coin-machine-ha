# Coin Machine for Home Assistant

The Home Assistant add-on listing for Coin Machine, an AI deal analyst for coin flippers, collectors and dealers.

Add this repository in **Settings > Add-ons > Add-on store > Repositories**:

    https://github.com/dsdadsasdaaaaaaaa/coin-machine-ha

The add-on's image is private. Before installing, add a `ghcr.io` registry with a GitHub token that has only
the `read:packages` permission (**Add-on store > Registries**). The add-on's Documentation tab has the full steps.
